Sitio en línea

Cada cambio en GitHub se publica solo.

Esta página no se sube manualmente. Al enviar un cambio al repositorio, GitHub Actions lo recibe y lo publica en Surge.sh en menos de un minuto.

Ver cómo funciona Perfil de GitHub

  1. Mi computadora

    Edito index.html y guardo el cambio con un commit.

    git push

  2. GitHub

    Recibe el código en la rama main.

    Repositorio actualizado

  3. GitHub Actions

    Ejecuta el workflow usando el token guardado como secret.

    Workflow completado

  4. Surge.sh

    Publica la nueva versión del sitio.

    Sitio actualizado

Cómo está armado

Tres piezas hacen posible que el despliegue ocurra sin intervención manual.

  1. Repositorio

    Una carpeta con Git y el archivo index.html, conectada a un repositorio en GitHub.

  2. Workflow

    El archivo .github/workflows/main.yml indica que cada push a main debe desplegar el sitio.

  3. Secret

    El token de Surge vive como SURGE_TOKEN en la configuración de GitHub y nunca aparece en el código.
